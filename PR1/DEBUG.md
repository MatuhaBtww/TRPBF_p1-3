# Отладка ПР1 в IDE
Это инструкция для самостоятельной демонстрации, а не запись ее выполнения.
1. Откройте main.py в своей IDE и выберите интерпретатор .venv.
2. Поставьте breakpoint на return в days_remaining.
3. Временно замените `(date.fromisoformat(deadline) - today)` на
   `(today - date.fromisoformat(deadline))`.
4. Запустите отладчик, выполните шаг внутрь функции. Посмотрите deadline,
   today и разность дат. Для будущего срока ошибочный результат отрицателен.
5. Верните исходный порядок вычитания и повторите запуск.
6. Для воспроизводимой проверки вызовите
   days_remaining('2026-09-30', date(2026, 9, 23)): ожидается 7.
При необходимости сохраните собственный скриншот breakpoint и переменных.
